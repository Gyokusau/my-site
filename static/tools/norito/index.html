組版の規則

六折の行数を揃えます。分割禁止に指定した神名などは改行せず、宣命書きの小字は行頭に置きません。最終行と強制改行の行は末尾を空け、その他の行は字間を調整して行末を揃えます。

印刷時は対応するカスタム用紙、倍率100%、ヘッダー・フッターなしを指定してください。プレビューには端末の日本語フォントを使用し、手書きの字形は再現しません。

仮名対応表の編集

一行に一つのひらがなを入力します。候補の漢字は / で区切り、最初の字を変換に使います。小字の判定にはすべての候補を使います。変更は以後の変換に適用され、現在の原稿は書き換えません。
